# Navigation (/docs/galactik/navigation)

Navigation components — Link, Tabs, Sidebar — for moving between views inside an application shell.



Components for moving around inside an application: a styled anchor, a tabbed panel switcher, and a
collapsible app-shell navigation panel with a built-in mobile drawer.
