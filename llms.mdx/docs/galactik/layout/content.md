# Layout (/docs/galactik/layout)

Panel layout — ResizablePanelGroup, ResizablePanel, ResizableHandle — for user-resizable panel arrangements.



Lay a row or column of panels out with a boundary the user can drag or arrow — the split view a filters panel
and a results panel, or an editor and a preview, typically need.
