# Layout (/docs/galactik/layout)

Panel and list layout — ResizablePanelGroup, ResizablePanel, ResizableHandle, SortableDirective, SwipeAction — for user-resizable panels, user-reorderable lists and rows a finger swipes.



Lay a row or column of panels out with a boundary the user can drag or arrow — the split view a filters panel
and a results panel, or an editor and a preview, typically need — let the user reorder the items of a list, and give a touch screen the swipe that stands in for a hover action.
