# Reference (/docs/atomic-angular/reference)

Feature flags, keyboard shortcuts and user settings/profile — looked up, not learned.



The type declarations in your editor are the exhaustive reference for every input, output and exported type —
duplicating them here would only let the two drift apart. This section stays small on purpose (DOCS-PLAYBOOK.md
§3) and exists only for the handful of things autocompletion cannot answer on its own — starting with which
configuration keys actually do something.
